# Windows 验收清单

在 Windows 10 或 Windows 11 上，使用正式安装包逐项确认。未通过的项目不要发布。

## 安装、升级与卸载

- 安装包的 SHA-256 与发布记录一致；若配置了代码签名证书，安装程序和主程序均显示有效签名。
- 全新安装不要求单独安装 .NET。
- 覆盖安装保留原保险库，并替换程序文件。旧版仍在运行时弹窗询问；确认后退出占用进程并继续安装，取消则中止。安装进度页的进度条与日志区保持窗口内容区全宽。
- 卸载默认保留缓存；勾选删除缓存后，保险库目录被删除。
- `extension\register-windows.ps1` 能写入 Chrome 与 Edge 的 Native Messaging 注册表项。
- 设置页「软件更新」能显示当前版本；有新 Release 时设置导航出现红点，可下载到安装目录 `cache\`，SHA-256 校验失败会删除文件；开始安装后主程序退出并打开安装程序，安装成功后 `cache` 中的安装包被清理。
- 便携解压版不提供自动下载安装，设置页可打开 GitHub 发布页。

## 保险库

- 创建时生成独立随机加密密钥；主密码、短密钥和数据密钥都不以明文出现在 `vault.kpvault` 中。创建后显示密钥并要求选择自定义文件夹保存 `.kpkey` 文件。
- 取消保存、关闭提示或保存失败后，下次解锁继续提示；成功后日常仍使用主密码/短密钥。密钥弹窗在锁定或主窗口隐藏时立即关闭并清除内容。
- 错误主密码无法解锁。更换主密码后旧密码对当前保险库失效，原有加密密钥和数据密文保持不变。旧版保险库第一次更换主密码时完成格式升级并提示保存新密钥。
- 设置中的短密钥与主密码六个输入框与锁定页共用英文输入限制：允许可打印 ASCII（英文字母、数字、英文符号及空格），禁用中文组词，含中文的输入/粘贴整次拒绝且保留原内容；显示密码后仍有效。分类和标签可正常输入中文。
- 新保险库不再提供安全问题恢复。使用密钥文件或完整密钥可以重置忘记的主密码；错误密钥不能修改文件。
- 空闲 5 分钟、锁屏和休眠后自动锁定。锁定后浏览器与 Windows 自动输入都不能取得密码。
- 加密备份不包含主密码保护层，只能使用对应的加密密钥还原。更改主密码前后的新版备份仍使用同一把密钥。来源密钥错误时当前条目不变；还原写入失败时原内容可继续使用。
- 明文 CSV 导出必须先验证当前保险库的加密密钥。仅提供主密码、短密钥或其他保险库的密钥不能导出；取消验证或保存位置选择时不产生明文文件。

## 浏览器

- 仅 Chrome 与 Edge。页面出现密码框时不自动弹窗。
- 聚焦密码框后，点击扩展按钮或按 Ctrl+Shift+L 才请求填充。
- 确认窗口同时显示目标站点、进程或页面，以及条目域名。短密钥错误时不填充。
- 未授权的本机进程即使连接本地端口，也得不到密码。

## Windows 程序

- 聚焦密码框时不自动弹窗。保险库运行期间，用户在密码框里按全局快捷键（默认 Ctrl+Alt+K，设置页可改）才请求填充；没识别到密码框时提示先点击密码框，锁定时提示先解锁。
- 设置页修改快捷键：被其它程序占用时提示并保留原快捷键；录制期间按当前快捷键不会触发填充；重启后保持新设置。
- 普通权限的密码窗口在用户选择账号并输入短密钥后，分别向识别出的用户名和密码控件模拟键盘输入；没有明确用户名框时只填密码。
- 窗口标题仅为“飞书”“新建连接”时，只要当前控件暴露 UIA 密码属性，就会展示可选账号，不要求标题包含域名。桌面候选包含登录、数据库、服务器和集群密码账号。
- DBX 多字段表单不会改写主机、端口、数据库名。用户名和密码相同时仍分别填入正确控件。
- 确认期间关闭目标窗口或目标控件失效时，显示失败原因，不能误报成功。
- 未暴露 UIA 密码属性的自绘输入框不保证自动识别，需要复制密码。
- Chrome 与 Edge 不走这条键盘路径。
- 以管理员身份运行的目标窗口会提示限制，程序不提权，也不输入密码。

## 界面过渡

- 六个主导航页面切换时淡入并轻微位移；重复点击当前页面不会重播动画，快速连续切页后只保留最后选择的页面且可操作。
- 打开、新建条目时右侧详情以固定 480px 宽度、约 260ms 从右滑入，关闭或确认删除时滑出；左侧短暂淡出后只重排一次再淡入。动画期间不逐帧改变布局宽度，类型/标签不能连续多次换行，详情字段不能挤压换行。
- 打开到一半点击空白处关闭、关闭到一半选择另一条、连续开关和取消“放弃修改”后，面板应从当前位置衔接并保持可操作；旧关闭/删除动作不能清空新记录。切页再返回不会停在半展开状态。
- 使用约 200 条记录、17 个标签，在默认宽度、最小窗口和最大化下打开/收起详情，每次左侧标签和条目只重排一次；从列表中部打开并关闭后，当前查看的条目仍在相近位置。已展开时切换条目只轻微过渡内容，不重放整个抽屉。
- 搜索连续输入时结果立即更新，短暂停顿后仅轻微过渡；不会先清空列表，也不会给每个虚拟列表卡片反复启动动画。
- 新增账号和集群节点有入场反馈；TOTP 每秒刷新只更新数值，不重复播放整页或卡片动画。
- 导入、确认、自动填充及备份密码弹窗内容淡入；标签下拉层、生成器模式、设置操作结果与错误提示有短过渡。
- 按钮按压、悬停、导航与卡片选中，以及输入框聚焦时颜色/阴影平滑变化。
- 切页、展开详情或弹窗动画进行时锁定，保险库内容立即隐藏；不会等待退场动画，也不会被旧解锁任务重新打开。
- 设置中的“界面动画”默认选择“流畅动画”，即使 Windows 关闭动画，页面/详情/弹窗仍正常过渡；选择“跟随系统”才遵循 Windows 动画开关；选择“减少动画”则立即切换页面和面板。选择应在重启后保留，切换主题或缓存目录不能覆盖它。
- 在 Windows 动画关闭的机器上实际打开、关闭详情，必须能观察到滑动中间帧，而不只是检查编译通过；固定宽度、单次重排、滚动位置、快速反向和锁定用独立 UI 回归测试覆盖。锁定、复制、保存和输入不依赖动画结束。
