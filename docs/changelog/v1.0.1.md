# 1.0.1

云同步不再需要 `.kpbind`，服务器也不再保存任何能解开保险库的数据。换电脑只带一份 `.kpkey`。需要配合服务端 1.0.1（先部署服务端）。

- 开启同步只填网站邮箱、网站密码和设备验证码。去掉「绑定密钥」一栏。网站密码只用于登录同步服务，不参与加密。
- 不再上传、下载用网站密码包裹的密钥包。首次建立和换钥只提交密文和密钥编号（`.kpkey` 文件名中的 12 位编号）。换钥不再需要填网站密码。
- 绑定时只用本机密钥尝试解开云端数据。解得开就合并；解不开时设备保持绑定、同步暂停，提示需要哪个编号的 `.kpkey`，选对后自动合并两边数据。解密失败绝不当成空库上传。
- 上传带上密钥编号。服务器发现与云端记录不同时拒绝写入，客户端暂停同步并提示该选哪一份密钥文件。
- 创建保险库时可选「使用已有加密密钥（换电脑）」：选中原来的 `.kpkey` 并设置本机短密钥，新保险库沿用同一把密钥，不再生成、也不再提示保存新密钥。之后绑定云同步即可直接下载数据。
- 设置 → 加密密钥 新增「重新导出加密密钥文件」。输入本机短密钥（旧格式为主密码）后可再保存一份同样的 `.kpkey`，用于原文件丢失但这台电脑还能解锁的情况。
- 0.9.1 已绑定的设备升级后无需重新绑定，下一次上传会补报密钥编号。0.9.1 客户端不能再新绑定设备，会提示升级到 1.0.1。
- 详情底栏统一：所有条目类型（登录、服务器、数据库，以及 SSH 密钥、API 凭据、集群服务）底部都是同一组按钮——「删除条目」在最左，「撤销修改」「保存修改」相邻靠右，文字水平、垂直居中。没有修改时撤销和保存灰色不可用；SSH 密钥、API 凭据、集群服务也新增了「撤销修改」。
- 详情头部统一：SSH 密钥、API 凭据、集群服务也改用新版头部——左侧类型图标，名称下方是类型标签和空间，右上只有收藏和关闭，名称可以直接点击修改。为这三种类型新增了线条图标。头部去掉「…」菜单，删除只在底栏。
- 修复：打开集群服务条目时详情会自动往下滚约 350px，最上面的「条目名称」被滚出视野。原因是「认证方式」分段切换在绑定选中项时把自己滚入视野，请求冒泡到了详情页。分段切换已不再自动滚动，设置页的主题、动画切换也不会再带动页面滚动。
- 开关缩小：生成器（包含数字、包含特殊符号、首字母大写、使用完整单词）、设置（开机启动、最小化启动）和详情里生成密码弹层的开关统一为 40×22（原来 58×34 和 46×28 两种）。
- 详情里的「生成密码」弹层改为画在窗口内：密码栏靠近窗口底部时自动翻到上方，不再伸出应用窗口。排版更紧凑：强度放到标题行，长度标签、滑块和数值同一行，开关为新的小尺寸。
- 「生成密码」弹层外观与详情卡片统一：白底（深色主题 #1B1E26）、卡片描边、14 圆角并带弹出阴影，替换原来的灰底小圆角；弹层里的结果框改为详情字段同款的中性灰描边，聚焦时不再出现蓝色粗框。
- 设备配对：换电脑不再需要密钥文件。新电脑登录官网账号后，在另一台已同步的电脑上核对 6 位确认码并批准，即可取得密钥、下载云端数据。服务器只中转临时公钥和加密信封，解不开。创建保险库时新增「从另一台设备同步（换电脑）」；云同步卡片新增「从其他设备获取密钥…」。原理见 docs/device-pairing.md。
- 本机已有数据时与云端合并：没有冲突直接上传；有冲突时逐条选择保留本机还是云端（默认较新的一边），取代原来的“确认合并 N 条”。
- 配对窗口同时显示二维码，为以后的手机端扫码批准做准备。
