# 0.9.1

云同步按服务端现有设备绑定接口对齐，不新增服务端路由。

- 开启同步仍是：发送设备验证码 → `POST /api/sync/device/bind` → 按响应处理密钥包 → 上传或合并保险库。不插入官网登录 JWT。
- 云端已有密钥包时先下载并用官网密码解开，再用解开的密钥读取、合并远端保险库。不再用本机数据密钥覆盖已有密钥包。
- 云端没有密钥包但已有保险库时，先确认本机密钥能解开该库，才能补传密钥包。解不开则停止，不上传、不覆盖。
- 绑定在保险库上传得到成功响应之后才显示已开启。上传前不把 `.sync` 写成已绑定；密钥包处理失败会调用 `unbind-self`，不留下本地绑定。
- 设备验证码按服务端 `device_bind`：8 位字母数字、15 分钟。发送接口返回 200 只表示请求被接受，不表示邮件一定发出，也不说明账号是否存在。
- 网络不可达、超时、取消、TLS、401、403、409、422、429 和 5xx 使用固定中文提示。设备令牌失效后停止轮询，保留本地保险库，直到用户重新绑定或断开。
