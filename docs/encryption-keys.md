# 独立加密密钥（0.6.0）

每个新保险库生成一把 256 位随机数据密钥。密码更换、短密钥更换及使用加密密钥重置密码，都不会改变它。数据使用 AES-256-GCM 加密；主密码经 Argon2id 派生的密钥只负责保护数据密钥。更换主密码时会重新生成盐和保护层随机数，数据密文、随机数及认证标签保持不变。

## 保存与使用

创建完成后显示完整密钥，用户选择文件夹保存 `.kpkey` 文件。默认文件名包含密钥指纹，以区分不同保险库。只有成功写入文件后才记录已保存状态；取消、写入失败或退出应用后，下次解锁会继续提示。关闭未完成的保存提示会返回锁定状态。保存完成后不再直接显示密钥。

密钥文件是长期有效的明文密钥副本，不是密码提示。持有密钥和对应的保险库或备份即可解密数据，也可以重置主密码。请永久保存，并与加密备份分开保管。更换主密码不会撤销这把密钥。

| 操作 | 所需凭据 |
| --- | --- |
| 日常解锁 | 主密码或已启用的本机短密钥 |
| 更换主密码或短密钥 | 当前主密码 |
| 导出加密备份 | 已解锁的保险库 |
| 从加密备份还原 | 该备份对应的加密密钥 |
| 导出明文 CSV | 当前保险库的加密密钥 |
| 忘记主密码后重置 | 当前保险库的加密密钥 |

从其他保险库的备份还原时，用来源密钥读取条目，再使用当前保险库的密钥保存。当前保险库的主密码、短密钥和加密密钥不会被来源替换。密钥不匹配时不修改当前内容，写入失败时恢复原有内存条目和标签。

## 文件格式与升级

日常文件为版本 2 的 `keep-password-vault`，含加密数据、Argon2id 参数及加密后的数据密钥。没有明文数据密钥。用于快速解锁的 `.quick` 文件仍单独保存在本机，Windows 上另有当前用户的 DPAPI 保护。

导出备份为版本 2 的 `keep-password-backup`，只包含账号标识和加密数据，不含密码保护层及短密钥信息。它不能作为日常保险库使用主密码打开，需通过“从备份还原”并提供密钥。手动复制日常保险库文件仍保留其密码解锁能力，和应用导出的备份格式不同。

版本 1 的旧保险库可继续解锁。更换一次主密码时生成随机数据密钥并重加密一次，移除原安全问题恢复，随后提示保存密钥文件。以后的主密码更换只更新保护层。新版不提供新建安全问题恢复；旧版已有安全问题仍可用于升级前的恢复。

旧备份不会自动转换，也没有新生成的密钥。要在新版还原流程中使用它们，先将旧备份作为旧保险库打开并升级，再重新导出。升级后的文件无法在旧客户端中打开；原始测试文件或备份不会被批量修改。

## 验证

核心回归覆盖随机密钥独立性、密码更换前后的密文一致性、主密码和短密钥解锁、密钥文件持久化、错误密钥拒绝、备份去除密码保护层、密码重置、旧版升级及写入失败回滚。

隔离界面测试使用临时保险库和模拟的保存路径，覆盖取消选择、保存失败后重试、关闭提示后的继续保存、错误凭据拒绝，以及锁定时立即关闭并清空密钥窗口。不会访问用户真实保险库。
